# Runtime + dev dependencies, pinned to the versions the suite is green on.
#
# These were lower bounds (`>=`) until 2026-09-17, which meant a deploy
# installed whatever had been published by build time rather than what was last
# tested — two deploys of identical source could ship different libraries, and
# a breaking release upstream would land in production with no commit to blame.
#
# Extras stay in the specifier deliberately: `uvicorn[standard]` pulls the
# uvloop/httptools accelerations and `psycopg[binary]` the prebuilt driver, and
# those resolve per-platform at install time. `pip freeze` cannot record an
# extra, which is why the Dockerfile installs *this* file and not
# requirements.lock — the lock is the transitive record, not the input.
#
# Bumping anything: change it here, run the suite, then regenerate the lock with
# `pip freeze > requirements.lock`.
#
# Python 3.11–3.14. psycopg (v3) is the Postgres driver used in prod; the test
# suite runs on stdlib sqlite and needs no driver.
